Frequently asked

How do I play?

Tap the Rules button in the game's toolbar for a complete walkthrough of the game's layout, controls, and win condition.

I lost a game I was in the middle of. Where did it go?

Starting a new deal while a game is in progress counts the abandoned game as a loss, with your statistics updated to reflect the cards you had built at the moment of abandonment. The old game is not recoverable from within the app. If you force-close the app without pressing Deal New Game, your in-progress game is restored automatically the next time you open the app.

Can I move my profiles between devices?

Yes. Use the Export Data button on the profile selection screen to save a JSON file containing all your profiles and statistics. On another device, use Import Data to bring the file in. Profiles never merge during import — if a name is already in use, the imported one is renamed (e.g., "Cameron (imported)").

Does the app use my data for anything?

No. All data stays on your device. See the Privacy Policy for the full details.

Does the game ever genuinely become unwinnable?

Yes. The game ends in a loss when the stock pile is empty and no legal moves remain anywhere on the table. While the stock still has cards, the game is effectively never blocked — drawing a stock card always opens a rank pile and changes the state. Most games end in a loss; a win is a real achievement.

Why does the toolbar wrap on my iPhone?

iPhone portrait mode has limited horizontal space, so the six toolbar buttons (Deal New Game, Undo, Hint, Stats, Rules, Profiles) wrap onto two rows under the title. On iPad and Windows the toolbar fits in a single row. This is intentional, not a bug.
